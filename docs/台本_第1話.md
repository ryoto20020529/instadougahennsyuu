# 第1話：白・黒・赤ニキビの違い｜生成用完成パッケージ

尺：50秒想定。動画生成AI（Runway/Pika/Kling等）と音声合成ツール（ElevenLabs等）にそのまま貼って使える形にしています。
※音声は実在人物の声のクローンではなく、「話し方の癖（低めのトーン・淡々とした間・ちょっと論理的な語り口）」をテキスト側で再現する形にしています。

## 3. ナレーション原稿（話し方の型）

低めのトーン、早口すぎない、「〜なんだよね」「〜って話で」「まあ結局」のような論理を積み上げる淡々とした話し方を意識したテキストです。実際に音声合成する際は、この原稿をお好きな声（クローンではなく通常のTTSボイス）に読ませてください。

```
[0:00-0:03]
そのニキビ、もう進行してるかもしれないんですよね。

[0:03-0:12]
ニキビって、白から黒、黒から赤って変わっていくんですけど、
これ実は全部"進行度"の違いなんですよ。

[0:12-0:20]
まず白ニキビ。これは毛穴が詰まり始めた、いわば初期段階なんですね。
この時点ではまだ炎症も起きてないので、一番ケアしやすい状態です。

[0:20-0:30]
それを放置すると、中身が酸化して黒ニキビになる。
色が変わっただけに見えるかもしれないですけど、
これは"時間が経った"っていうサインでもあるんですよね。

[0:30-0:40]
さらにそこから炎症が進むと、赤く腫れて赤ニキビになる。
ここまで来ると、跡が残るリスクも上がってくるんです。

[0:40-0:50]
なので結論としては、白ニキビの段階で触らずにケアするのが
一番跡になりにくいっていう話なんですよね。
保存しておくと、次見るとき役に立つと思います。
```

## 4. 音声合成についての補足

- 実在の人物（ひろゆきさん含む）の声を無断でクローン・模倣するのは権利侵害のリスクがあるので対応していません。
- 上のナレーション原稿は「淡々とした論理的な話し方」を再現したテキストなので、一般的なTTSボイス（男性・落ち着いたトーンの既製ボイス）に読ませるだけでも、雰囲気は近くなります。
- ElevenLabs等のツールには「Adam」「Josh」のような落ち着いた男性ボイスのプリセットがあるので、そのあたりを試すのがおすすめです。
- もし本当にそっくりな声質が必要な場合は、ナレーター自身（あなた）の声を録音してAIで軽く整える（ノイズ除去・トーン調整程度）方が権利的に安全です。
